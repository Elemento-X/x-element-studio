## F3.2 — Hero

**A** — `We engineer the systems your team stops doing.` *(brief placeholder, refined)*

## F3.4 — Process (4 steps)

**Step titles:** `Discover / Architect / Build / Scale` — **mantidos** (já são canonicamente "subject — verb — outcome", monosílabos, mapeiam aos artefatos).

### Section head

- **Eyebrow:** `Process` · **Number:** `004 · METHOD`
- **Title:** `Four phases. No ceremony.`
- **Lead:** Every engagement moves through the same four stages. Each phase produces an artifact the next one needs. No deck for the deck's sake.

### Steps

| # | Step | Artifact | Copy (≤35 palavras) |
|---|---|---|---|
| 01 | Discover | Signal brief | We map the system you already run. We surface the constraints nobody writes down. We name the one thing actually in the way — before anyone touches code. |
| 02 | Architect | System blueprint | We model the solution before we build it. Data contracts, interfaces, failure modes — written down, reviewed, signed. The build is execution, not discovery. |
| 03 | Build | Shipped surface | Typed code, observable from the first commit, shipped in production-sized slices. No staging theatre. No demo branches. The system you see is the system that runs. |
| 04 | Scale | Operational handoff | We harden it, document it, and hand over the keys. Your team operates the system without us. The engagement ends when the system runs alone — that is the point. |
